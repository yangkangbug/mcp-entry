# ADMIN 管理台使用路径

`/admin` 是独立的、显式启用的 loopback 管理平面，不是 `/account` 的改名版本。当前仅用于合成环境验证，不应填入真实外部服务凭据。

## 首次进入

1. 按 `admin-api.md` 的启动约束启用管理监听，并用**独立管理员 token**连接管理台。用户网关 token 不能作为管理凭据。管理员 token 仅在页面内存保留，断开、离开页面后清除；没有浏览器持久登录。
2. 在**概览 → 准备接入配置**填写服务 ID、固定 MCP 端点、认证模式与允许 IP。点击“加入本地草稿”只更新页面草稿。现有服务可在高级 JSON 中编辑或删除。
3. 点击**静态校验草稿**。成功只说明静态配置合法；不联网、不保存服务端草稿、不测试认证、不应用配置、不重启。拓扑变更的迁移与受控应用尚未实现，不可直接覆盖数据库或重新初始化来绕过限制。
4. 已配置用户在**工具与授权**按服务分组搜索、勾选工具；已选数量与新增/移除差异始终显示，完整工具名编辑收在高级模式。未发现目录中的已有授权单独列出并保留，不因搜索隐藏或目录缺失而删除。每次修改先预览，再核对身份、预期版本和完整新白名单后确认。空白名单移除全部工具授权。
5. 在**用户与入口 token**查看入口/绑定元数据，在单独的**危险操作**区预览并确认禁用身份或撤销单个绑定。禁用不能在此 UI 重新启用；先确认维护恢复路径。入口颁发/替换仍属于受信离线维护，管理台不会显示或生成入口秘密。
6. **运行与审计**手动读取最多前 100 条保留事件。HTTP 与操作拒绝摘要分列、重启清零；未知结果不得自动重放。P95 与全站成功率的采集限制收在概览说明中，不占用主要指标卡。

## 日常查看与信息边界

- 有服务时，概览首先显示**所选身份**的服务、凭据绑定、已发现/当前获准工具数量和需关注事项；只有零服务时才显示首次接入引导。不跨身份合并为“在线率”。
- 点击“查看服务”打开同页详情：完整端点、认证模式、所选身份绑定、目录、白名单成员与当前访问判定。当前获准和白名单成员分开，因为绑定/身份状态也会影响访问判定。服务详情中的审计入口打开全局保留样本，明确不宣称服务筛选。
- 缺少绑定记录、没有目录、认证健康未检查分别描述。当前接口没有最近健康检查时间或错误类别，因此不展示此类推测值。没有发现目录也不意味着没有授权或服务失败。
- 日期统一为可读 **UTC**，到期时间附相对天数；原始时间可展开。零时间显示未设置/未记录。入口“未撤销”不被描述为“有效”，原型用途、存储模式与下游可用性互不替代。
- 正常请求反馈为紧凑状态文字；错误保留醒目提示。帮助渐进展开，危险操作不再混入常规绑定表。
- 草稿页顶部明确**未应用**，只生成和静态校验。当前配置初始化高级 JSON 草稿时保留服务 `timeouts` 配置；此轮不增加结构化超时控件。颁发入口凭证、在线应用等未开放能力改为维护帮助，不提供假操作。

## 用户绑定不是管理台输入流程

管理员配置服务与授权后，用户用网关 token 连接 MCP 客户端。需要服务凭据时，应由客户端安全投递通道提交给后台，绑定到已认证身份与指定服务。当前已有 `--client-binding` 显式启用的合成本机 CLI 通道（见 `client-binding.md`），原生桌面客户端集成仍未验证；管理台不会要求员工打开绑定页，不提供服务 token 输入框，也不引导将秘密粘贴到聊天或普通工具参数。

- **管理员 token**：只认证管理平面。
- **用户网关 token**：只认证网关入口身份。
- **服务凭据**：只认证对应服务，不改变网关身份或工具授权。
- **已保存凭据 ≠ 已发现目录 ≠ 认证健康**：界面分别显示元数据、按身份保留的发现工具及“认证未检查”，不声称实时在线。

## 并发与失败

- 预览不是预留版本。确认时仍由后端 CAS 校验；409 显示冲突，不重试，刷新后重新预览。
- 503、断线或无法确认写结果不显示成功，不自动重复提交；先刷新核对状态。
- 已收到提交成功但读取新状态失败时，显示“已提交但刷新失败”，避免误导重复写入。
- 操作处理中禁止重复点击；可以断开连接。断开后的迟到响应（含 JSON 解码阶段）不能恢复旧会话。
- 语言切换不发请求，保留页面草稿与当前身份；切换页面取消尚未确认的预览。
