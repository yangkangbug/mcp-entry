# ADMIN 管理台使用路径

`/admin` 是独立的、显式启用的 loopback 管理平面，不是 `/account` 的改名版本。当前仅用于合成环境验证，不应填入真实外部服务凭据。

## 首次进入

1. 按 `admin-api.md` 的启动约束启用管理监听，并用**独立管理员 token**连接管理台。用户网关 token 不能作为管理凭据。管理员 token 仅在页面内存保留，断开、离开页面后清除；没有浏览器持久登录。
2. 在**概览 → 准备接入配置**先点击**读取运行配置并重置草稿**，取得权威服务注册表及版本（会替换本地草稿）。再填写服务 ID、固定 MCP 端点、认证模式与允许 IP；点击“加入本地草稿”只更新页面草稿。高级 JSON 可调整已有服务的 `timeouts`。此阶段不允许删除服务或修改已有服务的端点、认证、网络或配额。
3. 点击**静态校验草稿**只检查静态规则，不联网、不测试认证、不应用配置、不重启。如需实际应用，使用下方独立的**预览服务配置应用 → 确认应用服务配置**，核对新增服务、超时更新、完整目标配置、运行版本、摘要与票据到期时间。仅受支持的持久模式开放；成功应用与服务连通、服务认证、用户授权、凭据绑定、工具发现分开，不得将应用成功视为这些步骤已完成。
4. 已配置用户在**工具与授权**按服务分组搜索、勾选工具；已选数量与新增/移除差异始终显示，完整工具名编辑收在高级模式。未发现目录中的已有授权单独列出并保留，不因搜索隐藏或目录缺失而删除。每次修改先预览，再核对身份、预期版本和完整新白名单后确认。空白名单移除全部工具授权。
5. 在**用户与入口 token**明确填写 tenant/principal，预览并确认创建用户。新身份没有工具授权、不绑定服务凭据，也不自动颁发 token。受支持的持久模式后端才开放创建和入口生命周期能力；不支持时按钮禁用。
6. 为所选身份填写未来的 **UTC** 到期时间（`YYYY-MM-DDTHH:mm:ssZ`），预览颁发或轮换，再核对身份、入口版本、到期时间与影响并确认。已撤销的入口可颁发；未撤销的入口可轮换或撤销。轮换让旧 token 失效，撤销让当前 token 失效；均不增加工具权限。禁用身份不可执行入口操作。
7. 仅在颁发/轮换成功响应后展示一次入口秘密，明确标注为**用户网关 token，不是管理员 token**。通过受信私密通道交付，不放入聊天、日志或 URL；妥善保存后立即清除显示。切页、切换身份、刷新、离开页面、浏览器离线或断开连接均清除。服务器快照不会返回旧秘密。
8. 在单独的**危险操作**区预览并确认禁用身份或撤销单个服务绑定。禁用不能在此 UI 重新启用；先确认维护恢复路径。
9. **运行与审计**手动读取最多前 100 条保留事件。HTTP 与操作拒绝摘要分列、重启清零；未知结果不得自动重放。P95 与全站成功率的采集限制收在概览说明中，不占用主要指标卡。

## 日常查看与信息边界

- 有服务时，概览首先显示**所选身份**的服务、凭据绑定、已发现/当前获准工具数量和需关注事项；只有零服务时才显示首次接入引导。不跨身份合并为“在线率”。
- 点击“查看服务”打开同页详情：完整端点、认证模式、所选身份绑定、目录、白名单成员与当前访问判定。当前获准和白名单成员分开，因为绑定/身份状态也会影响访问判定。服务详情中的审计入口打开全局保留样本，明确不宣称服务筛选。
- 缺少绑定记录、没有目录、认证健康未检查分别描述。当前接口没有最近健康检查时间或错误类别，因此不展示此类推测值。没有发现目录也不意味着没有授权或服务失败。
- 日期统一为可读 **UTC**，到期时间附相对天数；原始时间可展开。零时间显示未设置/未记录。入口“未撤销”不被描述为“有效”，原型用途、存储模式与下游可用性互不替代。
- 正常请求反馈为紧凑状态文字；错误保留醒目提示。帮助渐进展开，危险操作不再混入常规绑定表。
- 本地草稿明确标注**未应用**；从运行配置读取或成功应用后标注**运行配置副本**，继续编辑则重新变为未应用草稿。高级 JSON 保留服务 `timeouts`；此轮不增加结构化超时控件。静态校验与真实应用是独立按钮和请求，后端不支持时禁用应用。
- 运行注册表与启动 seed JSON 分离。此服务数组不是可直接覆盖启动文件的完整配置，不能通过覆盖启动 JSON 或重新初始化数据库绕过迁移和安全限制；不提供误导性导出/重启按钮。

## 服务配置应用的并发与失败

- 预览基于 `/config/current` 返回的权威 revision；确认票据同时绑定 revision 与规范化目标 digest，短期、一次性。编辑草稿、取消或切页使前端确认失效；语言切换保留已核对的原始配置。
- 409 不重试，必须先**核对运行版本与摘要**再预览。破坏性变更返回明确错误，不降级成虚假应用成功。
- 断线、503 或无法确认应用响应时，不自动重放，且阻止新的应用预览；先 GET 核对当前 revision/digest。若摘要已匹配目标，提示勿再次提交；否则核对差异后重新预览。核对按钮保留本地草稿，读取并重置按钮会替换草稿。
- 已确认应用但 snapshot 刷新失败时，明确提示已应用、刷新失败；不误导重复提交。断开后的迟到响应不能恢复连接，跨页迟到预览不能生成确认按钮。

## 用户绑定不是管理台输入流程

管理员配置服务与授权后，用户用网关 token 连接 MCP 客户端。需要服务凭据时，应由客户端安全投递通道提交给后台，绑定到已认证身份与指定服务。当前已有 `--client-binding` 显式启用的合成本机 CLI 通道（见 `client-binding.md`），原生桌面客户端集成仍未验证；管理台不会要求员工打开绑定页，不提供服务 token 输入框，也不引导将秘密粘贴到聊天或普通工具参数。

- **管理员 token**：只认证管理平面。
- **用户网关 token**：只认证网关入口身份。
- **服务凭据**：只认证对应服务，不改变网关身份或工具授权。
- **已保存凭据 ≠ 已发现目录 ≠ 认证健康**：界面分别显示元数据、按身份保留的发现工具及“认证未检查”，不声称实时在线。

## 并发与失败

- 预览不是预留版本。用户/入口操作使用后端生成的短期、一次性、绑定原操作字段的确认票据；编辑表单、取消、切页或换身份使前端确认失效。确认仍由后端 CAS 校验入口代次；409 显示冲突，不重试，刷新后重新预览。工具授权继续使用现有策略版本 CAS 与草稿 stale guard。
- 503、断线或无法确认写结果不显示成功，不自动重复提交；先刷新核对状态与入口版本。若新 token 响应丢失，无法取回秘密；核对后需重新预览轮换（或按权威状态重新颁发），不能声称恢复旧 token。
- 已收到提交成功但读取新状态失败时，显示“已提交但刷新失败”，避免误导重复写入。
- 操作处理中禁止重复点击；可以断开连接。断开后的迟到响应（含 JSON 解码阶段）不能恢复旧会话。
- 语言切换不发请求，保留页面草稿与当前身份；切换页面取消尚未确认的预览。
